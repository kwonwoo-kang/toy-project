# spec: url-to-md

## 개요

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 추출해 화면에서 미리 보고, LLM(ChatGPT·Claude)에 바로 넘길 수 있는 단일 페이지 서비스다. 브라우저에서 URL → Markdown → AI 대화로의 흐름을 단 3단계로 줄인다.

## 범위

### 포함
- URL 입력 및 "변환" 버튼을 통한 Markdown 변환
- 변환 결과(페이지 제목·저자 헤더 + 렌더링된 Markdown) 표시
- 결과 복사하기 / `.md` 파일 다운로드
- 프롬프트(프리셋 3종 / 직접 입력) 선택 + ChatGPT·Claude로 열기
- 지우기 버튼(URL + 결과 완전 리셋)
- 다크모드 토글

### 제외
- 사용자 인증 및 변환 이력 저장 — MVP 단계; 개인화는 이후 고려
- 직접 입력 프롬프트의 영구 저장 — 요구사항 명시: 1회용
- 특정 도메인 최적화 — defuddle 기본 추출 범위를 그대로 사용

## 시나리오

### 1. URL 입력 후 Markdown 변환 성공

- **Given** — URL 입력 필드가 비어 있는 초기 화면
- **When** — 유효한 URL(`https://` 또는 `http://`로 시작)을 붙여넣고 "변환" 버튼 클릭
- **Then** — 로딩 인디케이터가 나타난 뒤, 페이지 제목·저자 헤더와 렌더링된 Markdown이 결과 영역에 표시된다

성공 기준:
- [ ] 유효한 URL 입력 → "변환" 버튼이 활성화됨
- [ ] 변환 버튼 클릭 직후 → 로딩 인디케이터가 표시됨
- [ ] 변환 완료 → 페이지 제목이 결과 영역 상단에 표시됨
- [ ] 변환 완료 → 추출된 본문이 렌더링된 Markdown으로 표시됨

---

### 2. URL 필드가 비어 있을 때 버튼 비활성화

- **Given** — URL 입력 필드가 비어 있는 초기 화면 또는 지우기 직후 화면
- **When** — (별도 행동 없음)
- **Then** — "변환" 버튼이 비활성화 상태로 표시되어 클릭할 수 없다

성공 기준:
- [ ] URL 미입력 상태 → 변환 버튼이 비활성화(disabled)로 표시됨

---

### 3. 잘못된 URL 형식 입력 → 인라인 에러

- **Given** — URL 입력 필드에 URL이 아닌 문자열(예: `not-a-url`, `hello world`)이 입력된 상태
- **When** — "변환" 버튼 클릭
- **Then** — 입력 필드 아래에 "유효하지 않은 URL입니다" 에러 메시지가 표시되고 결과 영역은 나타나지 않는다

성공 기준:
- [ ] 비-URL 문자열 입력 후 변환 → 입력 필드 아래 인라인 에러 메시지 표시
- [ ] 에러 발생 → 결과 영역이 표시되지 않음

---

### 4. 변환 실패 (페이지 접근 불가)

- **Given** — URL 입력 필드에 유효한 형식의 URL이 있지만 페이지를 가져올 수 없는 상태 (존재하지 않는 페이지, 접근 차단 등)
- **When** — "변환" 버튼 클릭
- **Then** — 입력 필드 아래에 변환 실패를 알리는 에러 메시지가 표시되고 결과 영역은 나타나지 않는다

성공 기준:
- [ ] 접근 불가 URL → 인라인 에러 메시지 표시
- [ ] 접근 불가 URL → 결과 영역이 표시되지 않음

---

### 5. 지우기 버튼 — 완전 리셋

- **Given** — URL 입력 필드에 URL이 있고 변환 결과가 화면에 표시된 상태
- **When** — URL 입력 필드의 지우기(×) 버튼 클릭
- **Then** — URL 필드가 비워지고 변환 결과 영역이 사라지며 화면이 초기 상태로 돌아간다

성공 기준:
- [ ] 지우기 클릭 → URL 필드가 빈 상태로 표시됨
- [ ] 지우기 클릭 → 결과 영역(제목·저자·Markdown)이 화면에서 사라짐
- [ ] 지우기 클릭 → 변환 버튼이 비활성화됨

---

### 6. 변환 결과 복사하기

- **Given** — 변환 결과가 화면에 표시된 상태
- **When** — "복사하기" 버튼 클릭
- **Then** — raw Markdown 텍스트(제목·저자 헤더 포함)가 클립보드에 복사되고 "복사됨" 피드백이 버튼에 표시된다

성공 기준:
- [ ] 복사하기 클릭 → 버튼에 "복사됨" 피드백(텍스트 변경 또는 아이콘 변화)이 표시됨

---

### 7. `.md` 파일 다운로드

- **Given** — 변환 결과가 화면에 표시된 상태
- **When** — ".md 다운로드" 버튼 클릭
- **Then** — 페이지 제목을 파일명으로 한 `.md` 파일이 다운로드된다

성공 기준:
- [ ] 다운로드 버튼 클릭 → `.md` 확장자 파일이 다운로드됨
- [ ] 다운로드 파일 내용 → 제목·저자 헤더와 본문 Markdown이 포함됨

---

### 8. 프롬프트 프리셋 선택 후 LLM으로 열기

- **Given** — 변환 결과가 표시된 상태, 프롬프트 프리셋("요약해줘" / "한국어로 번역해줘" / "쉽게 설명해줘") 중 하나가 선택된 상태
- **When** — "ChatGPT로 열기" 또는 "Claude로 열기" 버튼 클릭
- **Then** — 새 탭이 열리며 `[선택한 프롬프트]\n\n[Markdown 본문]`이 URL에 인코딩된 상태로 ChatGPT 또는 Claude 사이트로 이동한다

성공 기준:
- [ ] 프리셋 선택 + ChatGPT 열기 → 새 탭에서 chatgpt.com으로 이동, URL에 프롬프트와 Markdown이 포함됨
- [ ] 프리셋 선택 + Claude 열기 → 새 탭에서 claude.ai로 이동, URL에 프롬프트와 Markdown이 포함됨
- [ ] 프롬프트가 Markdown 본문보다 앞에 위치함

---

### 9. "직접 입력" 프롬프트 사용

- **Given** — 변환 결과가 표시된 상태
- **When** — 프롬프트 선택기에서 "직접 입력"을 선택하고, 나타난 텍스트 인풋에 커스텀 프롬프트를 입력한 뒤 "ChatGPT로 열기" 또는 "Claude로 열기" 버튼 클릭
- **Then** — 새 탭에 `[입력한 커스텀 프롬프트]\n\n[Markdown 본문]`이 URL에 담겨 전달된다

성공 기준:
- [ ] "직접 입력" 선택 → 텍스트 인풋 필드가 나타남
- [ ] 커스텀 프롬프트 입력 후 열기 → URL에 커스텀 텍스트가 Markdown 앞에 포함됨
- [ ] 다음 변환 또는 페이지 새로고침 후 → 직접 입력 텍스트가 보존되지 않음(1회용)

---

### 10. 프롬프트 미선택 시 LLM으로 열기

- **Given** — 변환 결과가 표시된 상태, 프롬프트 미선택
- **When** — "ChatGPT로 열기" 또는 "Claude로 열기" 버튼 클릭
- **Then** — Markdown 본문만 URL에 담겨 새 탭에서 ChatGPT/Claude로 이동한다

성공 기준:
- [ ] 프롬프트 미선택 + 열기 → URL에 프롬프트 없이 Markdown 본문만 포함됨

---

### 11. 다크모드 토글

- **Given** — 라이트 모드로 표시된 화면
- **When** — 다크모드 토글 버튼 클릭
- **Then** — 전체 UI(입력 영역, 결과 영역, 버튼, 에러 메시지 포함)가 다크 테마로 전환된다; 재클릭 시 라이트 테마로 복귀한다

성공 기준:
- [ ] 다크모드 토글 클릭 → 배경과 텍스트가 다크 테마로 변경됨
- [ ] 재클릭 → 라이트 테마로 복귀

---

## 불변 규칙

**내보내기 버튼 가용성**: 복사하기, `.md` 다운로드, "ChatGPT로 열기", "Claude로 열기" — 이 네 버튼은 변환 결과가 존재할 때만 활성화(또는 표시)된다. 변환 전·에러 상태·리셋 후에는 모두 비활성화 또는 숨김 상태다.
